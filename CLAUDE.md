# Currency converter

Keyboard-driven конвертер валют с калькулятором (в стиле Raycast): `10 usd - 10% to eur`.
Чистый Android + Jetpack Compose, сборка в Termux на телефоне. Меньше зависимостей, проще решения,
при выборе предпочитать кросс-платформенные варианты. Логика на чистом Kotlin, без `android.*`.
