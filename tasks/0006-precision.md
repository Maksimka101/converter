## Суть
Нужна точность до цента или копейки, но без лишней сложности.

## Обсуждение / варианты
- Идея пользователя: целая и дробная часть как 2 инта.
- Учесть крипту: у BTC 8 знаков после запятой, двух знаков мало.
- Округление при выводе по валюте (у JPY 0 знаков), группировка разрядов.
- Ресерч: [research/0006-precision.md](research/0006-precision.md) — варианты, плюсы и минусы, рекомендация (не решение).

## Решение
Принято 2026-09-22. Берём рекомендацию ресерча целиком.
- `BigDecimal` за собственной обёрткой `Num` в пакете `core` (чистый Kotlin, без `android.*`).
- Деление с `MathContext.DECIMAL128`.
- Курсы парсятся из строк, не через `Double`.
- Округление `HALF_UP` только при выводе: по таблице знаков валюты (JPY 0, USD 2, BTC 8),
  запасной вариант — по значащим цифрам.
- Обёртка `Num` оставляет путь в KMP через ionspin bignum, если понадобится.
- Идея «2 инта» отклонена: это Long с фиксированным масштабом, кода больше, крипта не влезает.
