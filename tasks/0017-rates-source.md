## Суть
Настоящий источник курсов с поддержкой крипты. Работа офлайн обязательна.

## Обсуждение / варианты
- Снапшот в APK не кладём: при первом запуске нужен интернет.
- Кэшировать последние курсы, показывать «курсы от <дата>», предупреждать об устаревании.
- Фоновое обновление (WorkManager) и обновление при старте.

## Решение
Принято 2026-09-22, приоритет понижен: UI и парсер важнее, пока работаем на моке (#15).
- Источник — **только fawazahmed0/exchange-api** (бывш. currency-api): статические JSON на CDN
  jsDelivr, без ключа и лимитов, 200+ фиатных валют вместе с криптой, обновление раз в сутки.
- ЕЦБ / frankfurter как основной **отклонён**: ЕЦБ не публикует справочный курс RUB с марта 2022,
  рубля там нет. Резервным источником оставлять его смысла мало — покрытие у него подмножеством.
- Риск: это репозиторий одного человека на GitHub, а не институциональный API. Митигация —
  обязательный офлайн-кэш (он и так нужен) плюс абстракция `RatesProvider`, чтобы источник
  менялся в одном месте. Запасной источник выберем, если основной начнёт подводить.
- Офлайн: последние курсы кэшируются (Room), в UI строка «курсы от <дата>», при устаревании
  (порог определим позже) — заметное предупреждение.
- Обновление: при старте, если кэш старше суток; фоновое через WorkManager — потом.
- **Сетевая библиотека выбирается здесь**: #2 решение отложил, потому что в первой версии сети нет.
  Кандидаты — Ktor client против голого `HttpURLConnection`; источник это один GET статического JSON.
