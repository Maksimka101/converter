## Суть
Выбрать библиотеки и структуру кода, убедиться, что всё собирается в Termux.

## Обсуждение / варианты
- Принципы: как можно проще, меньше зависимостей (телефону тяжело), при выборе предпочитать кросс-платформенные варианты.
- KMP/desktop не берём.
- Отдельные Gradle-модули `core`/`parser`/`app` отклонены 2026-09-24: обычный для Android один
  модуль `app` проще, а граница логики держится пакетами.
- SQLDelight отклонён — у пользователя часто ломался даже на небольших проектах; голый JSON —
  слишком жёстко для истории и frecency.
- Зависимости выбираем с оглядкой на сборку на телефоне: тяжёлые плагины, kapt/ksp-процессоры
  и нативные тулы могут не собраться под aarch64/Termux.

## Решение
Принято 2026-09-22.
- **UI**: Jetpack Compose, чистый Android. Логика — чистый Kotlin, без `android.*`, чтобы её можно было портировать.
- **Хранилище**: **Room** (androidx, есть версия под KMP).
- **Сеть**: в первой версии её нет — работаем на моке, выбор библиотеки отложен до реального
  источника курсов (#15): не тащим зависимость, которой полгода никто не воспользуется.
  Кандидаты: Ktor client (кросс-платформенный, в паре с KMP-Room сохраняет путь на другие платформы)
  против голого `HttpURLConnection` (источник — один GET статического JSON с CDN).
  Сериализация — kotlinx.serialization.
- **Числа**: `BigDecimal` за обёрткой `Num` в пакете `core` (#5).
- **Структура**: один модуль `app`, пакеты `core` (числа, валюты, frecency), `calc` (#3), `ui`.
  Всё, что не UI и не IO, живёт без `android.*`.
- **Тесты**: локальные unit-тесты `app/src/test` на JVM (гоняются без эмулятора).
- **Тулчейн** закрыт 2026-09-22: минимальное Compose-приложение собирается в Termux. Отдельный
  hello-world по adb не делаем — реальное приложение поедет на телефон в рамках #13, там же проверится запуск.
  Память Gradle и Kotlin daemon не замеряли, вернёмся, если начнёт мешать.

## Как реализовано
Скелет собран 2026-09-23, 2026-09-24 сведён в один модуль `app`. Пакет и `applicationId` —
`com.zemlianikin.currency`. Версии — в `gradle/libs.versions.toml`.
- Android SDK в `~/android-sdk`, x86-тулы (aapt2 и др.) заменены на aarch64 из Termux.
- Версии на момент проверки: AGP 9.4.1 (встроенный Kotlin, без kotlin-android), плагин compose 2.4.20,
  Gradle 9.7.1, compose-bom 2026.09.00, compileSdk 37, minSdk 26, JDK 21, Kotlin DSL.
- Холодная сборка ~2 мин, инкрементальная ~9 с. Debug APK 11.5 МБ.
- Room пока не подключён, PoC хранит frecency в SharedPreferences (#8); подключим с первой задачей,
  которой нужна БД.
