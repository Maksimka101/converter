## Суть
Считать frecency (частота + давность) по валютам. На её основе строится топ-N для автоконвертации (#9) и порядок в списке валют (#16).

## Обсуждение / варианты
- Предложение пользователя: засчитывать использование каждый раз, когда в выражение добавляется токен валюты.
- Риск: недонабранные токены (`eu`) могут засорить статистику.
- Порядок не должен прыгать во время ввода, иначе ломается мышечная память.
- Ресерч: [research/0008-frecency.md](research/0008-frecency.md) — варианты, плюсы и минусы, рекомендация (не решение).

## Решение
Принято 2026-09-22. Рекомендация ресерча (C + E) с одной правкой: **все веса равны 1**.

### Момент засчитывания
- Засчитывается множество **различных** валют итогового выражения, один раз на выражение.
- Триггер завершения: копирование результата, очистка поля, выход из приложения (`onStop`),
  пауза без правок ~3 с. Тот же триггер, что и запись в историю (#12).
- Промежуточные состояния ввода (`eu` → `eur`, backspace, правки) не засчитываются.
- Просмотр валюты в топ-N **не** засчитывается — иначе топ сам себя удерживает.
  Копирование конкретной строки топа (#11) засчитывает её валюту.

### Веса
- Вес всегда 1: и источник, и явная цель `to`, и копирование строки топа.
  Отдельный повышенный вес для `to` отклонён — лишняя настройка без доказанной пользы.

### Формула и хранение
- Экспоненциальный распад, период T = 21 день (константа, подобрать на практике).
- Хранится `score` + `updatedAt`, распад ленивый — при чтении и при добавлении.
- Валюты со `score` < 0.05 можно удалять из хранилища (как zoxide). Закрепления нет — #16 его отложил.

### Стабильность порядка
- Порядок топ-N **не пересчитывается во время ввода**: вычисляется и замораживается.
- Пересчёт при старте/возврате в приложение (`onStart`).
- Валюта источника выражения из топа исключается.
- Гистерезис (вытеснение только при перевесе 10–20 %) — опционально, если порядок окажется дёрганым.

### Холодный старт
- Дефолты из локали (валюта страны + USD, EUR, GBP, CNY/JPY) засеиваются как «виртуальный»
  малый score (~1.0), который естественно распадается и вытесняется реальным использованием.
- Отдельного экрана выбора на первом запуске нет (противоречит #13).

### Связь с историей
- Триггер общий с #12, хранение раздельное: запись истории содержит список валют (для будущего
  пересчёта), frecency живёт в своём сторе. Очистка истории не обнуляет топ.
