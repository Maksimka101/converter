## Суть
Список валют пополняется автоматически при использовании и ранжируется по frecency. Его можно редактировать.

## Обсуждение / варианты
- Из решения #5: на разбор выражения список **не влияет** — неоднозначные токены (`kr`) запрещены
  всегда, по всему справочнику. Список задаёт только состав и порядок топ-N (#9).
- Хотелки для экрана редактирования: закрепление на фиксированных местах, удаление, drag-сортировка.

## Решение
Принято 2026-09-22.
- Список пополняется **автоматически**: распознанная в выражении валюта попадает в список.
- **Экран редактирования пока не делаем**: ни закрепления, ни удаления, ни drag —
  это отдельная задача на потом, чтобы не раздувать первую версию.
- Стартовый список — дефолты из локали (#8, холодный старт).
- Поскольку список на разбор не влияет (#5), автопополнение ничего не ломает: максимум засоряет
  топ-N разово использованной валютой, и та сама выпадет по распаду frecency (#8).
